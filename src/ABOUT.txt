How to install?
===============

Linux
-----
Execute this command: (sudo) sh oStorybook.X.YZ.bin

Linux Debian
------------
Load the package oStorybook.X.YZ.deb

Windows
-------
Simply start the installer oStorybook.X.YZ.exe

Mac OS X
--------
Load the software with your usual setup tool with oStorybook.X.YZ.tgz.
