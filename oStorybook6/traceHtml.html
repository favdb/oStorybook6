Guide d'utilisation du logiciel TPhotos (anciennement JMOP)

1. Préambule

1.1. Introduction

Trier ses photos peut être une tâche longue et fastidieuse. Ce modeste logiciel vous permettra de simplifier ce travail en le ramenant à quelques clics de souris.

TPhotos peut vouloir dire:

  • Trieur et organisateur de photos
  • Tempo Photos: puisque les photos seront organisées chronologiquement
  • Tes Photos: parce que, après tout, ce sont tes photos que tu organise.

À vous de choisir la signification qui convient.

Important: le logiciel ne fait aucune modification du contenu des fichiers traités. La seule information modifiée est le nom du fichier. Plus les photos sont volumineuses plus l'affichage de celles-ci peut prendre du temps.

1.2. Principes

Les photos seront rangées dans un dossier spécial Photos dans le dossier personnel. Si le dossier Photos n'existe pas il sera créé, ainsi que tous les sous-dossiers nécessaires (les années et les éventuels mois et jours). Il est possible de choisir un autre nom, et une autre localisation, pour ce dossier de photos.

Les photos seront rangées par années, et si souhaité, par mois, ou même par jours.

Chaque fichier sera renommé en fonction de la date de la prise de vue telle qu'enregistrée dans les données EXIF. Si ces données EXIF n'existent pas c'est la date de création du fichier qui sera utilisée. Le format du nom sera AAAAMMJJ_hhmmss où AAAA est l'année, MM est le numéro du mois, JJ le numéro du jour dans le mois, hh l'heure, mm la minute, ss la seconde. Si des photos ont été prises en rafale plusieurs d'entre elles peuvent avoir un "horodatage" identique, dans ce cas après la première photos un suffixe est ajouté sous la forme _NN (NN étant un simple numéro d'ordre).

Après copie de la photo l'original pourra être supprimé, selon le choix à faire.

Une fois les photos bien rangées, il est possible de créer un Album qui consiste à dresser une liste des photos sélectionnées, accompagnées de petits commentaires.

L'Album étant constitué vous pourrez visualiser les photos en mode plein écran, c'est ce qu'on appelle un Diaporama.

1.3. Installation

Prérequis: la version 8 (au minimum) de Java doit être installée pour que le système soit en mesure d'exécuter un fichier jar directement via l'explorateur de fichiers avec un double-clic.

Installation standard sous Windows:

  • téléchargez et exécutez le fichier TPhotos.exe
    Remarque: Microsoft s'arroge le droit d'avoir l'exclusivité de ce que vous avez le droit de faire. En conséquence, tout logiciel qui n'a pas reçu son imprimatur est forcément un logiciel dangereux. Lorsque Windows vous posera les questions dites de sécurité, répondre que:
    • OUI vous voulez exécuter le programme d'installation de TPhotos
    • OUI vous voulez que le programme d'installation apporte des modifications au système
    • OUI vous savez ce que vous faites

Installation standard pour Linux:

Pour une distribution basée sur Debian téléchargez le fichier TPhotos.deb et installez le logiciel avec dpkg, en ligne de commande : sudo dpkg -i TPhotos.deb

Avec le navigateur de fichier il suffit de double-cliquer sur le fichier téléchargé, avec Firefox demandez simplement à ouvrir le fichier.

Pour une distribution basée sur Redhat (les RPM) utilisez le fichier TPhotos.rpm.

Installation manuelle:

  • créez un dossier d'installation dans votre dossier personnel, par exemple TPhotos
  • téléchargez et décompressez le fichier TPhotos.zip dans ce dossier
  • créez votre raccourci dans le menu des applications en vous référant aux instructions de votre système

Installation du programme seul:

  • Le fichier TPhotos.jar est à télécharger dans le dossier de votre choix. Je vous recommande de le mettre dans un dossier TPhotos (à créer s'il n'existe pas).

Si vous le souhaitez vous pouvez créer un raccourci dans votre menu général des applications en y ajoutant simplement une référence au fichier TPhotos.jar. (voir la documentation de votre système pour réaliser cette opération)

2. Organiser

2.1. Description

Au lancement, le logiciel affiche une fenêtre comme celle-ci:


[fenêtre Organiser]

Dans le titre vous avez le nom du logiciel, et la version, suivi entre parenthèse du dossier de vos photos, ou du nom du fichier Album, selon le contexte. Lorsque des modifications sont intervenues elles sont signalées avec des astérisques dans le titre de la fenêtre.

Vous pouvez changer de dossier photos en cliquant sur le bouton de repère (1) et choisir Dossier Photos.

À noter que le bouton Diaporama (4) n'apparaît que si votre Album contient au moins une photo.

Choisissez le dossier dans lequel se trouve les photos à ranger. Cliquez sur le bouton (6). Le dossier source actuel est rappelé dans la zone (5). Attention: TPhotos enchaîne automatiquement le traitement des sous-dossiers. Si le dossier sélectionné ne contient aucune photo un message d'avertissement apparaîtra dans la zone (10).

Une fois le dossier source sélectionné, choisissez éventuellement les options complémentaires (7) et (8), puis appuyez sur le bouton Organiser, repère (9).

La zone (10) récapitule les opérations qui sont effectuées.

Important: il n'y a pas de bouton pour quitter le logiciel. Utilisez la possibilité habituelle Alt+F4 ou cliquez sur la croix de fermeture (en général c'est dans le coin en haut à droite. Sauf que mon système est configuré à l'inverse, d'où cette différence sur les captures d'écran).

2.2. Compléments et options

Le dossier source peut aussi être n'importe quelle ressource connectée à votre PC, comme une clef USB, un disque dur externe, un smartphone.

Vous disposez de deux options complémentaires:

  • supprimer les originaux : Par défaut TPhotos conserve les photos originales. Cocher cette option permet de "nettoyer" simplement les fichiers de son appareil photo numérique connecté par exemple.
  • trier par : Dans le cas où vous avez un grand nombre de photos, sélectionnez l'une des options possibles de manière à les répartir par année, mois et éventuellement jour, ce qui devrait réduire le nombre de fichiers par sous-dossier. Les sous-dossiers par mois seront de la forme MM, ceux par jour seront de la forme JJ.

2.3. Collecte de photos

Vos photos sont maintenant bien rangées, puis un heureux événement survient: votre fille se marie. Bien entendu vous savez maintenant ranger vos nouvelles photos, mais peut-être que vous voudrez collecter les photos de vos proches et amis relatifs à cet événement en les regroupant. Voici une manière de procéder:

  • changez de dossier Photos, choisissez lui un nom (Mariage par exemple, que vous pourrez décider de mettre en sous-dossier de Photos).
  • rangez les photos qu'on vous a confié (sur une clef USB par exemple) en choisissant l'option trier par "aucun" (puisque toutes les photos ont été prises le même jour).

Ainsi toutes les photos du mariage seront réunies dans un sous-dossier unique. Vous pouvez même les "importer" dans des sous-dossiers différents, identifiés par le prénom de la personne auteur des clichés. Pour ça il suffit, à chaque fois, de changer de dossier Photos. Quand vous aurez terminé n'oubliez pas de revenir à votre dossier Photos principal.

3. Album

3.1. Description

Lorsque vous appuyez sur bouton Album l'écran se présente sous la forme suivante:


[fenêtre Album]

Rappel: le bouton Diaporama n'apparaîtra que si votre album contient au moins une photo.

La fenêtre est composée de trois parties:

  • à gauche il y a l'arborescence de votre dossier Photos.
  • au centre l'espace dédié à l'affichage du sous-dossier sélectionné sous forme d'une planche contact.
  • à droite c'est votre album proprement dit sous forme d'un tableau.

Lorsque vous sélectionnez un sous-dossier, la fenêtre se présente ainsi:


[exemple d'aperçu pour une photo sélectionnée]

Lorsque vous sélectionnez une photo, pour la mettre dans votre album, elle sera encadrée de rouge et le bouton plus, en haut, sera accessible. Pour ajouter la photo à l'album il suffit donc d'appuyer sur le plus. Le dialogue suivant s'ouvre:


[dialogue commentaire]

Définissez le modèle de commentaire qui vous convient. À tout instant vous pouvez insérer la date, selon l'un des formats proposés. La date sera insérée entre accolades. Voici un exemple de ce qui peut être obtenu:

Premiers tours à vélo {MMM AAAA}

Les types de représentation de la date:

  • AAAA: année seulement
  • MM/AAAA: numéro du mois et année
  • MMM AAAA: nom abrégé du mois et année
  • JJ/MM/AAAA: date numérique traditionnelle (jour, mois et année)
  • JJ MMM AAAA: jour, nom du mois abrégé et année

Une fois validé, même si le modèle de commentaire est vide, la photo (ou les photos) est ajoutée au tableau à droite.

Concernant ce tableau, représentant l'Album:

  • pour supprimer une ligne: sélectionnez la ligne puis appuyez sur la touche suppr.
  • pour déplacer une ligne: sélectionnez la ligne, puis utilisez la combinaison Ctrl+Monter ou Ctrl+Descendre.

La petite icône à droite du titre permet de visualiser l'album sous forme d'une planche contact.

3.2. Compléments

Remarques

Une photo encadrée en bleu indique qu'elle est déjà dans l'album.

Une photo encadrée de rouge indique qu'elle est sélectionnée pour être ajoutée à l'album.

Astuces

Si vous faites un clic droit sur une photo un menu contextuel s'ouvre vous proposant:

  • d'ouvrir la photo avec le logiciel par défaut (sur ma configuration Linux Mint c'est Xviewer
  • si la photo n'est pas déjà dans l'album (donc non encadré de bleu):
    • d'ajouter la photo à l'album
    • de changer la date, et donc son rangement
    • de supprimer la photo
  • sinon d'ajouter la photo à l'album

Le logiciel n'est pas prévu pour modifier le contenu d'une photo, si vous voulez modifier l'orientation, par exemple, ouvrez la photo avec un outil de retouche photo. Dans mon cas, avec Xviewer, je peux double-cliquer la photo et ainsi appliquer la rotation nécessaire, puis enregistrer ma modification.

Changer la date

Vos photos sont rangées par année, par mois et par jour (éventuellement). Mais vous rencontrez un problème, il y a quelques années vous aviez numérisé d'anciennes photos de votre grand-mère. Elles avaient été prises en 1963, et maintenant elles se retrouvent rangées en 2017 (date à laquelle vous aviez numérisé ces photos). Pour les ranger à la bonne date, puisque vous connaissez la vraie date de prise de vue, faites un clic droit sur la photo. Un menu contextuel s'ouvre vous proposant soit d'ajouter la photo à l'album (c'est la même chose que lorsque vous faites un double-clic), soit de changer la date. Si vous choisissez de changer la date, le dialogue suivant s'ouvre:


[dialogue pour changer la date]

  • Si la photo contient une information EXIF la date de prise de vue est rappelée, sinon c'est la date du fichier d'origine qui est indiquée.
  • Dans la zone "Nouvelle date" vous pouvez changer chacun des éléments affichés (jour, mois, année, heure, minute et seconde).
  • Sélectionnez l'option de tri, comme lors de l'organisation initiale.

Après avoir validé, la photo sera rangée dans le bon sous-dossier.

Note importante: le logiciel ne modifie en rien le contenu du fichier, seul son nom change. Les données EXIF, si elles existent, sont préservées. Aucune donnée EXIF n'est ajoutée.

Modifier le commentaire

Si vous voulez modifier le commentaire d'une photo il suffit de double-cliquer sur le commentaire en question dans le tableau de droite.

Si vous voulez modifier le commentaire pour une série de photos:

  • sélectionnez les photos concernées dans le tableau de droite
  • faites un clique droit sur l'une des lignes sélectionnées. Un menu contextuel apparaît vous proposant "Modifier les commentaires"
  • cliquez sur cet élément, le dialogue de commentaire s'ouvrira pour enregistrer vos indications

4. Diaporama

Les photos de votre album s'afficheront en plein écran.

Touches du clavier:

  • à droite → : photo suivante
  • à gauche ← : photo précédente
  • début ⌂: première photo
  • Fin : dernière photo
  • Échap. : arrêter le diaporama

5. Exporter

5.1. Description

Vous avez donc rangé vos photos, puis vous vous êtes constitué un album que vous avez pu visualiser avec le diaporama. Maintenant ce serait bien de pouvoir envisager de partager cet album avec vos proches. C'est ce que propose la fonction Exporter. Vous avez peut-être remarqué que lorsque vous avez commencé à ajouter des photos dans l'album, ce bouton est apparu. Il va vous proposer l'affichage suivant:


[capture d'écran Exporter]

Vous devrez choisir:

  • le format de ce que vous voulez obtenir,
  • le niveau de compression des images,
  • le dossier où enregistrer votre export.

Les formats:

- dossier simple: c'est un dossier qui contiendra une copie des photos sélectionnées dans votre album, auquel on ajoute un fichier Album.xml spécifique (pour ne pas mélanger avec votre fichier album). La visualisation se fait avec TPhotos (qui inclura les commentaires) ou avec n'importe quel logiciel de visualisation d'images (sans les commentaires).

- dossier HTML créera un dossier directement téléchargeable sur votre serveur Web. Dans ce cas il est recommandé de choisir une compression "minimum" pour éviter de saturer votre espace d'hébergement. À noter que, au lieu de télécharger sur le Web, vous pourriez compresser le dossier et l'envoyer à vos proches. La visualisation se fait avec un navigateur Web quelconque (Firefox par exemple).

- fichier EPUB: le format EPUB est utilisé sur les liseuses pour les livres numériques. L'intérêt du fichier EPUB c'est que c'est un fichier unique qui ne nécessite aucune transformation ultérieure. La visualisation se fait avec une Liseuse qui supporte le format EPUB, ou avec une tablette ou un PC doté d'un logiciel comme FBReader.

- fichier MP4: c'est une vidéo directement utilisable sur n'importe quel appareil qui sait lire ces fichiers (votre téléviseur dernier cri par exemple). Dans ce cas vous devrez compléter vos choix en sélectionnant une temporisation pour rythmer votre diaporama, ou/et inclure une page de titre. Attention: vous ne verrez ce format, et ne pourrez l'utiliser, que si vous avez installé au préalable le logiciel FFmpeg. La visualisation d'un fichier MP4 se fait à l'aide d'un logiciel de visualisation de vidéo, celui disponible par défaut sous Windows ou encore VLC.

5.2. Complément

Concernant le "poids" des fichiers exportés, voici une petite comparaison au sujet des effets de la compression (sur un échantillon de 10 photos prises avec un smartphone).

  • sans compression: 2,6Mo
  • compression moyenne: 1Mo
  • compression maximum: 0,664Mo

Pour un fichier EPUB ou MP4 c'est au moins la compression moyenne qui est appliquée.

Remarque: la compression implique une perte de qualité de la photo (un très léger effet de flou, une diminution du contraste des couleurs). La plupart du temps ces effets passent inaperçus sauf à avoir sous les yeux, simultanément, l'original et le fichier compressé.

Astuce

Le dossier simple est très similaire à votre dossier Photos à tel point que vous pouvez l'ouvrir comme votre dossier Photos. À vous de découvrir comment employer cette particularité.
